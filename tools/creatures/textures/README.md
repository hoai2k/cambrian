# Shared generated cuticle albedo

`chitin-albedo.png` was generated with the built-in imagegen tool and visually
inspected on 2026-09-06. Used by the arthropod and radiodont builders with
species pigment and separately authored normal detail. Pigmentation is
artistic reconstruction, not recovered fossil coloration.

Prompt:

Natural believable living marine arthropod surface. Very fine detail, low to moderate contrast, even diffuse illumination, no highlights, no cast shadows, no perspective, no objects, no animal, no text, no border, no UV islands.

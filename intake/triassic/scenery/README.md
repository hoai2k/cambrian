# Triassic organic-scenery intake

These reference sheets are the approved starting point for the four organic scenery
models in the Triassic brief. Each folder contains a canonical four-view sheet
(`turnaround.png`) and its side, top, and three-quarter input crops. They use a
plain neutral grey studio field so the eventual mesh boundary is unambiguous.

The images were generated directly from the briefs in `prompts.json`; no external
source images were used. `log-raft` deliberately contains only the drift trunk:
its crinoid colony is an in-engine procedural assembly.

## Landed this session, beyond the bodies themselves

- **Every animal is drawn in its own authored colours.** The whole roster named an alternate scheme,
  so nothing was ever drawn in the colours its builder gave it. `CREATURE_SCHEMES` is now empty but
  for Shonisaurus on `basin-slate`.
- **The roster was showing paintings instead of models.** A builder renders four portraits into its
  own `portraits/` folder and stops there until a human ships the animal; shipping never did the
  copy, across 24 animals. `publish-portraits.mjs` does it and runs inside `npm run triassic`. Four
  ichthyosaurs still have no portrait step in their builder at all.
- **The original pose can be seen beside the base pose.** Five bodies had their mesh unbent before
  binding, and there was no way to see what changed. `base-poses.mjs` publishes each untouched
  generation and the viewer's Model control offers it.
- **Five animation faults corrected**, each of which an existing check was asking the wrong question
  about, so every audit was raised rather than relaxed. The one worth remembering: Keichousaurus'
  swim read as *reversed* while every per-joint number was correct, because where a station goes is
  the summed swing of everything in front of it times its own lever arm.

## Environment notes worth not rediscovering

- Blender 5.2.1 at `/opt/blender/blender`. **EEVEE and Workbench need EGL, which this container does
  not have** — render CYCLES on CPU. `tools/triassic/tripo/review.py` dies at its render step for
  that reason; import it and call `audit`/`export_preview` directly.
- **Blender exits 0 when a builder raises**, so a failed build reports success and leaves stale
  artefacts looking fresh. Every kit installs an excepthook now.
- **Decoded copies go stale** unless written *after* the repack; one agent nearly wrote a defect
  into a README that was only a body two builds old.
- Raw Tripo bodies are unstitched patch soup: weld at 0.0005 before any connected-component or
  Laplacian work.
- Three agents concurrent is the working ceiling; five hit a session-wide rate limit that killed
  them all. Commit-and-push-as-you-go belongs in every agent prompt — the batch that had it lost one
  partial file to a container restart, the batch that did not lost hours.

# Placeholder portraits

These `<id>.select.png`, `<id>.card.png` and `<id>.thumb.png` files are placeholders: each is cut from that animal's canonical pose in `docs/triassic/canonical/` by `tools/triassic/placeholder-portraits.mjs`, not rendered from a model. Keichousaurus uses its male pose. They stand in until each creature's real model lands and is rendered into these same files per `docs/creature-intake.md`. Nothing in this directory is a model.
